# EnterpriseAI organization configuration

This repository is the reviewed source for the public `eai-support` organization
profile, default community-health files, and policy validation. It is not a
support intake queue: Issues, Discussions, Wiki, and Pages remain disabled
here.

Use the organization profile to choose a support route. Public questions,
feedback, and sanitized defect reports belong in the `community` repository.
Confidential support and vulnerability details must use the explicitly marked
private routes.

Changes to policies, routes, templates, workflows, or security settings require
a pull request, two approvals, a Code Owner review, and the required policy
checks. The repository remains held from publication until its separate
preparation, restricted-canary, activation-smoke, and customer-promotion gates
pass.
